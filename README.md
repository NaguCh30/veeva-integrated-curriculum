# Veeva Integrated Curriculum

A structured collection of notes, assignments, programming exercises, case studies, and practical implementations completed as part of the **Veeva Integrated Curriculum**.

This repository documents my learning and practical progress in **Software Development, Software Testing, and Test Automation**, with an emphasis on strengthening programming fundamentals, problem-solving abilities, testing concepts, and automation skills.

---

## About This Repository

The purpose of this repository is to maintain the concepts, assignments, practical exercises, and implementations covered throughout the curriculum in one organized place.

It emphasizes learning through practical implementation rather than limiting knowledge to theoretical explanations.

The repository includes:

- Software development and testing fundamentals.
- Programming exercises and problem-solving.
- Java programming and Object-Oriented Programming.
- Real-world software development case studies.
- Jira-based assignments and test management activities.
- Web technologies and Selenium prerequisites.
- Selenium WebDriver and browser automation.
- Future test automation tools, frameworks, and practical projects.

This repository will continue to evolve as I explore new concepts, complete assignments, and build practical implementations throughout the curriculum.
