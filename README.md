# Veeva Integrated Curriculum

A structured collection of projects, assignments, coding exercises, case studies, and practical implementations completed as part of the **Veeva  Integrated Curriculum**.

This repository documents my learning journey in Software Testing, Java Programming, and Software Development Engineer in Test (SDET) concepts through hands-on practice.

---

## About This Repository

The purpose of this repository is to maintain all the concepts, assignments, practical exercises, and implementations covered throughout the curriculum in one organized place.

Rather than keeping theoretical knowledge separate, this repository focuses on applying concepts through:

- Programming exercises and problem-solving.
- Real-world software development case studies.
- Software development and testing fundamentals.
- Jira-based tasks and practical assignments.
- Java programming and object-oriented concepts.
- Future automation testing exercises and projects.

The repository will continue to grow as I progress through the curriculum.
