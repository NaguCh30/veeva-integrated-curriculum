# Case Study 1 on Files

You are asked to develop a sample Java application to manage student data in a file called `student.txt` or as a collection of records.

Student Records are stored as normal text in text file.

The attributes for the student records are:

- Roll Number
- Name
- Age
- Telugu
- English
- Maths
- Science
- Social
- Grade

You should create a **menu-driven Java application** to perform CRUD operations on the student file.

## Menu

1. **Add Record**
2. **Add All Records**
3. **Read Record on Roll Number**
4. **Read Records on Name**
5. **Delete Record on Roll Number**
6. **Update Record on Roll Number**
   - Update Age
   - Update Name
   - Update Both Age and Name
7. **Exit**
