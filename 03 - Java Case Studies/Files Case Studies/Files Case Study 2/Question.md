# Case Study 2 on Files

You are asked to develop a sample Java application to manage student data in a file called `student.dat` or as a collection of records.

Student records must be stored as Java objects using **Object Serialization**. You should use `ObjectOutputStream` and `ObjectInputStream` to write and read student objects from the file.

The attributes for the student records are:

- Roll Number
- Name
- Age
- Telugu
- English
- Maths
- Science
- Social
- Grade

You should create a **menu-driven Java application** to perform CRUD operations on the student file using Java Object Serialization.

## Menu

1. **Add Record**
2. **Add All Records**
3. **Read Record on Roll Number**
4. **Read Records on Name**
5. **Delete Record on Roll Number**
6. **Update Record on Roll Number**
   - Update Age
   - Update Name
   - Update Both Age and Name
7. **Exit**
